# Statistics Module

## Purpose
Tutor-facing statistics that summarize learning progress across students.

## Responsibilities
- Aggregate typing and reading results per student.
- Provide overall stats and per-student summaries.
- Present statistics in SwiftUI.

## Key Types
- `StatisticsViewModel`, `StatisticsView`
- `StudentStats`, `OverallStats`

## Dependencies
- Core
- UserManagement
- UserProgress
