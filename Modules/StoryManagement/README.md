# StoryManagement Module

## Purpose
Tutor-only UI for creating, editing, and deleting custom stories.

## Responsibilities
- Manage story CRUD flows and validation rules.
- Provide SwiftUI screens for the list and story form.

## Key Types
- `StoryManagementViewModel`
- `StoryManagementView`
- `StoryFormView`
- `StoryDraft`, `StoryFormError`

## Dependencies
- Stories
