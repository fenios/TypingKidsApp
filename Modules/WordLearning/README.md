# WordLearning Module

## Purpose
Presents vocabulary words with clipart images to help children connect words with visuals.

## Responsibilities
- Load vocabulary words and their image URLs.
- Orchestrate image loading and UI state.
- Provide a SwiftUI screen with word + image and next controls.

## Key Types
- `VocabularyWord`
- `VocabularyRepository`, `LocalVocabularyRepository`
- `WordLearningViewModel`, `WordLearningView`

## Dependencies
- Clipart
- AccessibilitySettings
