# TypingPractice Module

## Purpose
Typing practice flow where children copy Spanish stories and get feedback.

## Responsibilities
- Typing session lifecycle and metrics computation.
- Sanitized input for Spanish ISO keyboard layout.
- Persist typing results per user.

## Key Types
- `TypingResult`, `TypingSessionState`
- `TypingEvaluator`
- `TypingPracticeViewModel`
- `TypingPracticeView`

## Dependencies
- Core
- Stories
- AccessibilitySettings
- UserProgress
