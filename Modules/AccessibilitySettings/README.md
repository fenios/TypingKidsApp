# AccessibilitySettings Module

## Purpose
User-configurable accessibility options.

## Responsibilities
- Store and persist font scale and high contrast options.
- Provide a view model and SwiftUI view for settings.

## Key Types
- `AccessibilitySettings`
- `AccessibilitySettingsRepository`
- `DefaultAccessibilitySettingsRepository`
- `AccessibilitySettingsViewModel`
- `AccessibilitySettingsView`

## Dependencies
- Core
- Persistence
